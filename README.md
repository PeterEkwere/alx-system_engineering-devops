# ALX — System Engineering & DevOps

Shell scripting, Linux system administration and DevOps projects from the ALX Software Engineering program.

## Projects

| Area | Topics |
|---|---|
| Shell | basics, permissions, redirections, variables & expansions, loops & conditions |
| Processes | processes & signals, regular expressions |
| Networking | networking basics 1 & 2, SSH, firewall |
| Web stack | web infrastructure design, load balancer, HTTPS/SSL, web server, MySQL |
| Operations | configuration management, APIs, web-stack debugging, monitoring, postmortem |

## Usage

Shell scripts follow Betty style and start with `#!/usr/bin/env bash`:

```bash
chmod +x script
./script
```

## Tech

Bash · Linux · Nginx · HAProxy · networking · MySQL
